# WordPress.org assets

This directory is reserved for Plugin Directory assets and is intentionally
excluded from installable plugin archives.

Expected files:

- `banner-772x250.png`
- `banner-1544x500.png`
- `icon-128x128.png`
- `icon-256x256.png`
- `screenshot-1.png`
- `screenshot-2.png`
- `screenshot-3.png`

The screenshot numbering must remain aligned with the `Screenshots` section in
`readme.txt`. These files belong in the top-level `assets` directory of the
WordPress.org SVN repository, not in `trunk` or the distributed plugin ZIP.
